# Diversity-selected fractal pre-training on digits

Fractal pre-training is a way to initialise neural networks with synthetic images generated by iterated function systems, before any real data is seen. The paper "Improving fractal pre-training" (2022) argues that the choice of synthetic images matters, not just their quantity. This experiment asks whether a budget of synthetic fractal images selected for diversity can do at least as well as a random budget on a small downstream task.

**Question:** Can fractal pre-training with a small, cheaply generated synthetic budget, chosen by diversity, match or beat fractal pre-training with a larger random budget on a small downstream digit-recognition task?

**Dataset:** scikit-learn's bundled optical recognition of handwritten digits (1,797 8x8 images, loaded with `load_digits`, no download). A stratified 70/30 train/test split uses a fixed seed, and only 20 labelled training digits per class are used for fine-tuning. This is not the paper's own dataset.

**Baseline:** an MLP pre-trained on a random budget of procedurally generated IFS fractal images (labelled by generating IFS class), then fine-tuned on the labelled digits.

**Improved model:** the same MLP, architecture, fine-tuning and budget, but the fractal images are chosen by k-means diversity from a larger candidate pool.

## How to run

```
pip install -r requirements.txt
python analysis.py
```

Results: written to `results.json` (and `figures/macro_f1.png`).
